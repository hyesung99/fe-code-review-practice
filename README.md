# 연습 마켓

커머스 도메인 코드 리뷰 연습용 프로젝트예요. 상품 목록, 상품 상세, 장바구니, 리뷰 작성/수정 화면이 있어요.

## 실행

```bash
npm install
npm run dev
```

- API는 `src/api`의 목(mock) 서버가 대신해요. 응답은 0.3~1초 지연되고, 결제는 10% 확률로 실패해요.
- 새로고침하면 데이터가 초기화돼요.
- 쿠폰: `WELCOME10`(10%), `SAVE20`(20%, 5만원 이상)
